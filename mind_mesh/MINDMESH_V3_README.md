# MINDMESH — The Human Signal Field Atlas

**Edition 03 · Version 3.0.0 · 160 cards · 16 chapters · 100 research sources**

MINDMESH is a self-contained, evidence-linked trivia and calibration game about human communication: emotion, empathy, listening, culture, groups, conflict, trust, influence, leadership, relationships, feedback, pragmatics, motivation, identity, and related human systems.

## Start

Open `mindmesh_field_atlas_v3.html` in a modern browser. No installation, build step, account, or server is required. The game itself has no external code, font, image, analytics, or network dependency. Internet access is needed only when you choose to open an evidence link.

For the most portable setup, keep the HTML file and this README together. Progress, notes, and resumable sessions are stored locally when the browser permits local storage for local files.

## Three play formats

- **Solo fieldwork:** scored play with confidence wagers, streaks, calibration, and blind-spot routing.
- **Table relay:** two to six teams rotate turns on one device, with protected pass-the-device handoffs and team-specific scores and streaks.
- **Open notebook:** unscored study mode for discussion, explanations, hints, practical transfer moves, and source browsing.

## Session controls

Choose 12, 24, 40, 80, or every eligible card. Filter by any combination of the four difficulty bands and 16 chapters. Route construction can be balanced across chapter and difficulty, weighted toward weak areas, weighted toward unseen cards, or randomized. A session code makes ordinary balanced/random routes reproducible.

Optional timers are 30, 60, or 90 seconds. Confidence can be logged at 55%, 70%, 85%, or 95%. Each card contains three progressively revealing margin notes, an explanation, a practical field move, a boundary condition, and direct evidence links.

## Keyboard controls

- `1`–`4`: select an answer
- Arrow keys while answers are focused: move and select within the answer group
- `H`: reveal the next margin note
- Left/Right Arrow outside the answer group: change confidence
- `Enter`: lock the answer or continue
- `Escape`: close ordinary dialogs

A skip link, live regions, visible focus treatment, reduced-motion handling, high-contrast support, roving radio focus, and modal focus restoration are included.

## Report and export

The field report separates:

- raw accuracy,
- average confidence,
- confidence–accuracy gap,
- expected calibration error,
- Brier loss,
- a confidence-versus-observed-accuracy plot,
- chapter results with sample size,
- team standings,
- suggested review cards,
- and a complete answer ledger.

Use **Export JSON** to save a machine-readable session record, or **Print report** for a paper/PDF copy. The report explicitly treats short-session chapter and calibration numbers as sample estimates rather than personality or EQ scores.

## Data and privacy

The app runs entirely in the browser. It does not transmit answers, notes, team names, progress, or analytics. Evidence links open the cited third-party source in a separate tab. **Erase local history** removes the app's locally stored progress and notes for that browser profile.

## Files

- `mindmesh_field_atlas_v3.html` — complete standalone application
- `mindmesh_question_bank_v3.json` — editable source bank
- `MINDMESH_V3_AUDIT.md` — content, leakage, interaction, and test audit
- `previews/` — representative desktop and mobile captures

## Important limitation

MINDMESH is an educational knowledge-and-calibration game. It is not a clinical instrument, a validated psychometric EQ test, a personality assessment, or a substitute for direct conversation, context, or professional judgment.
